## Refresh command
From this frontend directory:
```powershell
.\Refresh-Projections.ps1
```
Then click Refresh in the browser. Use -ExportOnly if the model has already been updated. A hosted Netlify deployment needs a new build/deploy after syncing JSON. No backend, database or authentication was added.
